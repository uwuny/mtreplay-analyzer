# Разбор реплеев «Мир танков»

Статический сайт: кидаешь `.mtreplay` — получаешь таблицу боёв, карту с
движением техники, 3D-визуализатор попаданий и сводку по игрокам.

Файлы никуда не отправляются: реплей разбирается прямо в браузере, результат
хранится локально (IndexedDB). Сервер не нужен — только раздача статики.

## Что где

    index.html            приложение
    src/                  разбор реплея и сборка отчёта
    templates/            страницы карты боя и визуализатора попаданий
    assets/tokens.css     цвета, скругления, тайминги
    icons/                иконки техники
    MapElement/           маркеры баз и точек возрождения
    maps/                 картинки карт + definitions/ с игровыми XML
    maps/index.json       список имеющихся картинок
    objects/              коллизионные модели техники (.obj) для визуализатора попаданий
    vehicles/             распакованные игровые XML: броня узлов и снаряды
    backgrounds.png       фон страницы
    tank_db.txt           короткие названия техники
    .nojekyll             отключает обработку Jekyll

Картинки карт — облегчённые (`*_low.png`). Без полноразмерных в карте боя
гаснет кнопка «высокое разрешение», всё остальное работает.

## Требования

Браузер с поддержкой `DecompressionStream`: Chrome/Edge 80+, Firefox 113+,
Safari 16.4+.
